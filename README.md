
## Запуск проекта

__Перед запуском проекта необходимо установить зависимости. 
Как это сделать для каждой из OS, описано в файле 
[INSTALL](./INSTALL.md)__.

Чтобы запустить проект в первый раз, используйте команду:


```bash
make build
```

Чтобы запустить уже собранные контейнеры, используйте команду:

```bash
make run
```

Чтобы остановить и удалить контейнеры, используйте команду:

```bash
make down
```

## Миграции
Чтобы пересобрать, запустить контейнеры и применить миграции, используйте команду:

```bash
make build-migrate
```

Чтобы создать новую пустую миграцию с заданным именем, используйте команду:

```bash
make create-empty-migration
```


Чтобы применить все непримененные миграции, используйте команду:

```bash
make run-pending-migrations
```

Чтобы откатить последнюю примененную миграцию, используйте команду:

```bash
make run-downgrade
```

Чтобы узнать, в каком статусе миграции проекта, используйте команду:

```bash
make status
```
